# Meetings

This directory captures team meeting artifacts required by the CSE 110 process rubric.

## Layout

| Folder | Cadence | What's captured |
|---|---|---|
| `standups/` | 3× per week (Mon / Wed / Fri) | What each team did since last standup, what they're doing next, blockers. One file per sprint, with three dated entries inside. |
| `ta/` | Weekly | Notes from the weekly meeting with TA Audria. One file per week. |
| `prof/` | At least once before end of quarter | Notes from the meeting with Professor Powell. |

## Conventions

- Files are markdown.
- Each entry leads with a date (`## YYYY-MM-DD`) and an attendee list.
- Blockers and decisions are called out explicitly so they're searchable later.
- Standups don't need everyone present — async updates in Slack are summarized here when a team member couldn't make the call.
